# Alibaba PuHuiTi 2.0

Original, complete WOFF2 fonts embedded locally for both Chinese and English.

- Family: Alibaba PuHuiTi 2.0 / 阿里巴巴普惠体 2.0
- Weights: 55 Regular (400), 65 Medium (500), 75 SemiBold (600), 85 Bold (700).
- Publisher: Alibaba (China) Co., Ltd. / 阿里巴巴（中国）有限公司。
- Official font portal: https://www.alibabafonts.com/
- Official distribution: https://fonts.alibabadesign.com/AlibabaPuHuiTi-2/
- Publisher's font and legal statement: https://done.alibabadesign.com/puhuiti2.0
- Download provenance and SHA-256 hashes: `manifest.json`.

The fonts are not modified or renamed. Keep publisher notices with the files.
The UI serves them from `/fonts/`; no remote font request or OS installation is needed.
To refresh the original files, run `scripts/fetch_ui_fonts.py` in the project Docker image with the project mounted at `/workspace`.
